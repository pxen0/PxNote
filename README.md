## Özellikler

- Notlara başlık ve isteğe bağlı açıklama ekleme
- Bildirim veya gerçek alarm seçeneği
- Notları sabitleme ve tamamlanan olarak işaretleme
- Türkçe, İngilizce ve İspanyolca dil desteği
- Açık ve koyu tema
- Notları yerel cihazda saklama

## Kurulum

### Android

1. [En son APK dosyasını indir](https://github.com/pxen0/PxNote/releases/latest/download/PxNote.apk).
2. `PxNote.apk` dosyasını aç.
3. Android, bilinmeyen uygulamalara izin istiyorsa bu kaynağa izin ver.
4. Uygulamayı yükle ve notlarını oluştur.

### Kaynaktan çalıştırma

```bash
flutter pub get
flutter run
```

## Android sürümünü derleme

```bash
flutter build apk --release
```

Derlenen dosya: `build/app/outputs/flutter-apk/app-release.apk`
